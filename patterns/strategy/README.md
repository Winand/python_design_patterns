# Strategy Pattern
**Strategy** pattern enables selecting an algorithm at runtime to reduce coupling. Different
strategies can be implemented as a set of functions or as an abstract class (or protocol)
and its concrete subclasses. [OOP approach](https://www.youtube.com/watch?v=UPBOOIRrl40&t=647s)
allows to set parameters of a strategy on its initialization or using setter methods. In functional
approach [closures](https://www.youtube.com/watch?v=n2b_Cxh20Fw&t=1365s) can be used for that.

For comparison, see the [Template Pattern](../template/README.md).
It uses inheritance to modify behavior of the base class at design time.
