# Strategy Pattern
**Strategy** pattern enables selecting an algorithm at runtime. Different
strategies can be implemented as a set of functions or as an abstract class
and its concrete subclasses. OOP approach [allows](https://www.youtube.com/watch?v=UPBOOIRrl40&t=647s)
to set parameters of a strategy on its initialization or using setter methods.

For comparison, see the [Template Pattern](../template/README.md).
It uses inheritance to modify behavior of the base class at design time.
